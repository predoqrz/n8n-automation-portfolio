# Como solicitar acesso a sistemas

> Empresa fictícia (Grupo Aurora), criada para o portfólio. Nenhum procedimento aqui é real.

## Quem pode pedir

Só o **gestor direto** pode solicitar acesso para alguém da equipe. Pedidos feitos pelo
próprio colaborador são devolvidos sem análise.

## Como pedir

1. Abra um chamado no portal de TI, categoria **Acessos**.
2. Informe: nome completo do colaborador, sistema, perfil de acesso e justificativa.
3. Anexe a aprovação do gestor (e-mail ou print do Teams).

## Aprovações por sistema

| Sistema | Quem aprova além do gestor | Prazo |
|---|---|---|
| ERP (financeiro e estoque) | Controladoria | 3 dias úteis |
| CRM (vendas) | Gerente comercial | 2 dias úteis |
| Pasta de RH no SharePoint | Diretoria de RH | 5 dias úteis |
| Demais sistemas | Ninguém além do gestor | 2 dias úteis |

O prazo conta a partir da última aprovação, não da abertura do chamado.

## Acesso temporário

Acesso para prestador de serviço ou estagiário é sempre temporário, com data de
expiração obrigatória de no máximo **90 dias**. Para renovar, abra um novo chamado antes
do vencimento — acesso expirado não é renovado, é solicitado de novo.

## Revisão trimestral

Todo trimestre, cada gestor recebe a lista de acessos da equipe e tem **10 dias** para
confirmar ou remover cada um. Acesso não confirmado no prazo é removido automaticamente.
