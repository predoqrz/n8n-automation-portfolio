# Equipamentos de TI: pedido, troca e devolução

> Empresa fictícia (Grupo Aurora), criada para o portfólio. Nenhum procedimento aqui é real.

## Pedido de equipamento

O gestor abre o chamado na categoria **Equipamentos**. Padrão por função:

| Função | Equipamento padrão |
|---|---|
| Administrativo | Notebook 14", 16 GB de RAM |
| Desenvolvimento e dados | Notebook 16", 32 GB de RAM |
| Atendimento em loja | Desktop compartilhado (sem notebook) |

Monitor adicional e headset são liberados para qualquer função, mediante pedido do gestor.
Prazo de entrega: **5 dias úteis** para item em estoque; **20 dias úteis** se for preciso
comprar.

## Troca por defeito

Notebook com defeito é trocado em até **2 dias úteis**. Leve o equipamento à TI com o
número do chamado; seus arquivos ficam no OneDrive, então não é preciso fazer backup manual.

## Perda ou roubo

1. Registre boletim de ocorrência.
2. Abra um chamado na categoria **Segurança** em até **24 horas**, anexando o boletim.
3. A TI bloqueia o equipamento remotamente e libera um substituto.

## Devolução

No desligamento, o equipamento é devolvido no **último dia de trabalho**, junto com o
crachá. A TI apaga os dados e o equipamento volta para o estoque.
